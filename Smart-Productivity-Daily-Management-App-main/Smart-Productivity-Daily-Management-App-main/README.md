# 📱 SmartFlow - All-in-One Productivity App

SmartFlow is a complete task, notes, expense & events management app built with React Native & Expo.

![Expo](https://img.shields.io/badge/Expo-000020?style=for-the-badge&logo=expo&logoColor=white)
![React Native](https://img.shields.io/badge/React_Native-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)

## ✨ Features

### 📊 Dashboard
- Daily summary with tasks, expenses & upcoming events
- Quick stats & progress tracking

### ✅ Task Management
- Add/Edit/Delete Tasks
- Priority: High / Medium / Low
- Description, Due Date & Reminder Time
- Status: Pending / Completed

### 📝 Notes
- Add/Delete Notes
- Search Notes (Title + Content)
- Categorize: Work, Personal, Ideas, Study, Other
- Pin/Unpin Important Notes
- Auto Date & Time

### 💸 Expense Tracker
- Amount Tracking
- Category: Food, Travel, Bills, Shopping, Health, Other
- Payment Method: Cash, UPI, Card, NetBanking
- Category-wise / Weekly / Monthly Overview
- Total Spent, Remaining Budget Calculation
- Budget Progress Bar (₹20,000 monthly)

### 📅 Events & Reminders
- Event Types: Meeting, Birthday, Payment Reminder, Other
- Repeat Options: Once, Daily, Weekly, Monthly, Custom (X days)
- Actions: Complete ✓, Snooze ⏰ (10 min), Reschedule ↻
- Date & Time Picker

### 🎨 UI/UX
- Dark Theme: Background #0F0F14, Card #1E1E26, Primary #6366F1
- Loading, Empty & Error States
- Form Validation
- Responsive Design

## 🛠️ Tech Stack

- **Frontend:** React Native, Expo, React Navigation
- **Backend:** Node.js, Express, MongoDB (Mongoose)
- **Storage:** AsyncStorage, MongoDB
- **UI:** Custom Components, Vector Icons

## 📦 Installation

```bash
# Clone repo
git clone https://github.com/YOUR-USERNAME/SmartFlow.git
cd SmartFlow

# Install dependencies
npm install

# Start Expo
npx expo start
